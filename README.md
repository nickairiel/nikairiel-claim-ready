# Claim Ready — Warranty Checklist

A light, editorial landing page built with Next.js following the `sorry-bravia-emerald-editorial-DESIGN.md` specification and `content.txt`.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
npx next dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- **Editorial Design System**: Implements the Emerald Editorial specifications (Plus Jakarta Sans, JetBrains Mono, exact color tokens, fluid typography, and rounded components).
- **Faithful Content**: Every section and exact wording from `content.txt` without extraneous text.
- **Mobile Responsive**: Fully responsive layout with mobile-optimized single-line header, touch targets, and stacked cards.
- **Utility Actions**: Downloadable checklist `.txt` file, one-click link sharing to clipboard, and print-ready styles.
